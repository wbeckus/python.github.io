1. print() & Comments

print() shows something on the screen. Anything after # is a comment — Python ignores it.

# This is a comment
print("Hello, world!")
print("Age:", 15)            # commas add a space between items
print("a", "b", "c", sep="-")  # change the separator
print("No newline", end=" ")   # change what goes at the end
print("same line!")
Hello, world! Age: 15 a-b-c No newline same line!

2. Variables & Data Types

A variable is a name that stores a value. You don't need to say the type — Python figures it out.

name = "Alex"       # str   (text)
age = 16            # int   (whole number)
height = 5.9        # float (decimal number)
is_student = True   # bool  (True or False)
nothing = None      # NoneType (no value)

print(type(name))   # check a variable's type
print(type(age))
<class 'str'> <class 'int'>

You can assign several variables at once:

x, y, z = 1, 2, 3
a = b = 0          # both are 0
x, y = y, x        # swap two values

3. Getting Input with input()

input() pauses the program and waits for the user to type something. It always returns a string, even if the user types a number.

name = input("What is your name? ")
print("Hi,", name)

# Numbers must be converted!
age = int(input("How old are you? "))
print("Next year you will be", age + 1)

price = float(input("Enter a price: "))
print(f"With tax: {price * 1.08:.2f}")
What is your name? Sam Hi, Sam How old are you? 14 Next year you will be 15 Enter a price: 10 With tax: 10.80

Reading two values on one line

a, b = input("Enter two numbers: ").split()
a, b = int(a), int(b)
print(a + b)

# Shorter version using map()
a, b = map(int, input("Enter two numbers: ").split())
Enter two numbers: 4 7 11

Yes / no questions

answer = input("Continue? (y/n): ").strip().lower()
if answer == "y":
    print("Continuing...")

💡 .strip() removes extra spaces and .lower() makes "Y" and "y" both work.

⭐ Reading a List of Numbers in One Line

This is one of the most useful lines in beginner Python:

numbers = [int(n.strip()) for n in input("Enter numbers separated by commas: ").split(",")]
print(numbers)
print("Total:", sum(numbers))
Enter numbers separated by commas: 5, 10, 15,20 [5, 10, 15, 20] Total: 50

How it works (read it inside-out)

  1. input("Enter numbers separated by commas: ") → the user types "5, 10, 15,20" (a string).
  2. .split(",") → cuts the string at each comma: ["5", " 10", " 15", "20"]
  3. for n in ... → goes through each piece one at a time.
  4. n.strip() → removes extra spaces: " 10" becomes "10"
  5. int(...) → turns the text into a real number: "10" becomes 10
  6. [ ... ] → collects all the results into a new list.

The same thing written the long way

text = input("Enter numbers separated by commas: ")
pieces = text.split(",")
numbers = []
for n in pieces:
    numbers.append(int(n.strip()))
print(numbers)

Useful variations

# Numbers separated by spaces (split() with no argument splits on any whitespace)
nums = [int(n) for n in input("Enter numbers: ").split()]

# Decimal numbers
prices = [float(p.strip()) for p in input("Prices: ").split(",")]

# Words, cleaned up
names = [w.strip().title() for w in input("Names: ").split(",")]

# Using map() instead
nums = list(map(int, input("Enter numbers: ").split()))

💡 int() actually ignores spaces on its own, so int(" 10") works — but .strip() is a good habit, especially for strings.

6. Strings

f-strings (the easiest way to format text)

name = "Maya"
score = 92.456
print(f"{name} scored {score:.1f} points")   # .1f = 1 decimal place
print(f"2 + 3 = {2 + 3}")                      # you can do math inside {}
Maya scored 92.5 points 2 + 3 = 5

Common string methods

s = "  Hello World  "
s.strip()            # "Hello World"     remove spaces at the ends
s.lower()            # "  hello world  "
s.upper()            # "  HELLO WORLD  "
s.strip().title()    # "Hello World"     capitalize each word
s.replace("World", "Python")   # "  Hello Python  "
s.strip().split(" ") # ["Hello", "World"]
"-".join(["a", "b", "c"])      # "a-b-c"
"hello".count("l")   # 2
"hello".find("l")    # 2  (index of first match, -1 if not found)
"hello".startswith("he")  # True
"123".isdigit()      # True
"abc".isalpha()      # True

Indexing & slicing

word = "Python"
#       012345
print(word[0])     # P     first letter
print(word[-1])    # n     last letter
print(word[0:3])   # Pyt   index 0 up to (not including) 3
print(word[2:])    # thon  from index 2 to the end
print(word[::-1])  # nohtyP  reversed
print(len(word))   # 6

Strings can be joined with + and repeated with *: "ha" * 3 → "hahaha".

7. Lists

A list holds many values in order. Lists can be changed.

fruits = ["apple", "banana", "cherry"]

fruits.append("mango")       # add to the end
fruits.insert(0, "kiwi")     # add at a position
fruits.remove("banana")      # remove by value
last = fruits.pop()          # remove & return the last item
fruits[0] = "grape"          # change an item

print(fruits)
print(len(fruits))           # how many items
print("apple" in fruits)     # check if something is in the list
['grape', 'apple', 'cherry'] 3 True

More list tools

nums = [4, 1, 9, 3]
nums.sort()                  # sorts in place → [1, 3, 4, 9]
nums.sort(reverse=True)      # → [9, 4, 3, 1]
nums.reverse()               # flip the order
new = sorted(nums)           # returns a NEW sorted list
nums.index(9)                # position of 9
nums.count(4)                # how many 4s
nums.extend([7, 8])          # add many items
copy = nums.copy()           # make a copy
nums.clear()                 # empty the list

Slicing works the same as strings: nums[1:3], nums[-1], nums[::-1].

8. List Comprehensions

A short way to build a new list from another one. Pattern: [expression for item in list if condition]

nums = [1, 2, 3, 4, 5, 6]

squares = [n ** 2 for n in nums]          # [1, 4, 9, 16, 25, 36]
evens   = [n for n in nums if n % 2 == 0] # [2, 4, 6]
doubled = [n * 2 for n in range(5)]       # [0, 2, 4, 6, 8]
words   = ["hi", "hello", "hey"]
lengths = [len(w) for w in words]         # [2, 5, 3]
labels  = ["even" if n % 2 == 0 else "odd" for n in nums]

# Dictionary and set comprehensions too
squares_dict = {n: n ** 2 for n in range(4)}   # {0: 0, 1: 1, 2: 4, 3: 9}
unique_lens  = {len(w) for w in words}         # {2, 3, 5}

💡 The ⭐ featured input line is a list comprehension!

9. Tuples & Sets

Tuples — like lists, but can't be changed

point = (3, 5)
print(point[0])     # 3
x, y = point        # "unpacking"
# point[0] = 10     # ❌ error — tuples are unchangeable

Sets — no duplicates, no order

colors = {"red", "blue", "red", "green"}
print(colors)              # {'red', 'blue', 'green'}  (duplicate removed)
colors.add("yellow")
colors.discard("blue")

# Remove duplicates from a list
nums = [1, 2, 2, 3, 3, 3]
unique = list(set(nums))   # [1, 2, 3]

a = {1, 2, 3}
b = {2, 3, 4}
print(a | b)   # union        {1, 2, 3, 4}
print(a & b)   # intersection {2, 3}
print(a - b)   # difference   {1}

10. Dictionaries

A dictionary stores key: value pairs — like a real dictionary stores word: definition.

student = {"name": "Leo", "age": 15, "grade": "A"}

print(student["name"])            # Leo
print(student.get("email", "none"))  # safe lookup with a default
student["age"] = 16               # change a value
student["school"] = "Lincoln"     # add a new key
del student["grade"]              # remove a key

for key, value in student.items():
    print(key, "=>", value)
Leo none name => Leo age => 16 school => Lincoln
student.keys()      # all the keys
student.values()    # all the values
"name" in student   # True — checks keys

# Counting things with a dictionary
word = "banana"
counts = {}
for letter in word:
    counts[letter] = counts.get(letter, 0) + 1
print(counts)       # {'b': 1, 'a': 3, 'n': 2}

11. if / elif / else

Run code only when a condition is true. Indentation (4 spaces) matters!

score = int(input("Enter your score: "))

if score >= 90:
    print("A")
elif score >= 80:
    print("B")
elif score >= 70:
    print("C")
else:
    print("Keep practicing!")
Enter your score: 85 B
# One-line if (ternary)
age = 17
status = "adult" if age >= 18 else "minor"

# Check a range
if 1 <= age <= 100:
    print("valid age")

# Empty things count as False
items = []
if not items:
    print("The list is empty")

12. Loops

for loops & range()

for i in range(5):          # 0, 1, 2, 3, 4
    print(i, end=" ")

for i in range(1, 11, 2):   # start, stop, step → 1 3 5 7 9
    print(i, end=" ")

for i in range(10, 0, -1):  # count down
    print(i, end=" ")

for letter in "cat":        # loop through a string
    print(letter)

enumerate() — get the index too

fruits = ["apple", "banana", "cherry"]
for i, fruit in enumerate(fruits, start=1):
    print(i, fruit)
1 apple 2 banana 3 cherry

zip() — loop through two lists together

names = ["Ann", "Ben"]
scores = [90, 85]
for name, score in zip(names, scores):
    print(f"{name}: {score}")
Ann: 90 Ben: 85

while loops

count = 3
while count > 0:
    print(count)
    count -= 1
print("Liftoff!")

# Keep asking until the user types "quit"
while True:
    cmd = input("Type something (quit to stop): ")
    if cmd == "quit":
        break          # exit the loop
    if cmd == "":
        continue       # skip to the next round
    print("You typed:", cmd)

💡 break stops the loop completely. continue skips to the next round.

13. Functions

A function is a reusable block of code. Define it with def, send it values (parameters), and get a result with return.

def greet(name):
    print(f"Hello, {name}!")

greet("Zoe")

def add(a, b):
    return a + b

result = add(3, 4)
print(result)        # 7
Hello, Zoe! 7

Default values & keyword arguments

def power(base, exp=2):
    return base ** exp

print(power(5))          # 25   (uses default exp=2)
print(power(2, 3))       # 8
print(power(exp=3, base=4))  # 64  (named arguments)

Returning more than one value

def stats(numbers):
    return min(numbers), max(numbers), sum(numbers) / len(numbers)

low, high, avg = stats([4, 8, 15, 16, 23, 42])
print(low, high, avg)   # 4 42 18.0

Putting it together with input

def get_numbers():
    return [int(n.strip()) for n in input("Enter numbers separated by commas: ").split(",")]

def average(nums):
    return sum(nums) / len(nums)

nums = get_numbers()
print(f"Average: {average(nums):.2f}")
Enter numbers separated by commas: 3, 6, 9 Average: 6.00

15. lambda, map() & filter()

A lambda is a tiny one-line function with no name.

square = lambda x: x ** 2
print(square(6))     # 36

nums = [1, 2, 3, 4, 5]

# map() — do something to every item
doubled = list(map(lambda x: x * 2, nums))      # [2, 4, 6, 8, 10]

# filter() — keep only items that pass a test
odds = list(filter(lambda x: x % 2 == 1, nums)) # [1, 3, 5]

# Sort a list of tuples by the second value
people = [("Ann", 30), ("Bob", 22), ("Cy", 27)]
people.sort(key=lambda p: p[1])
print(people)   # [('Bob', 22), ('Cy', 27), ('Ann', 30)]

16. Error Handling (try / except)

Stop your program from crashing when something goes wrong — like a user typing letters instead of a number.

try:
    age = int(input("Enter your age: "))
    print("In 10 years you'll be", age + 10)
except ValueError:
    print("That's not a whole number!")
Enter your age: twelve That's not a whole number!

Keep asking until the input is valid

while True:
    try:
        numbers = [int(n.strip()) for n in input("Enter numbers separated by commas: ").split(",")]
        break
    except ValueError:
        print("Please only enter numbers, like: 1, 2, 3")

print("You entered:", numbers)
try:
    result = 10 / 0
except ZeroDivisionError:
    print("Can't divide by zero")
finally:
    print("This always runs")

Common errors: ValueError, TypeError, ZeroDivisionError, IndexError (list index too big), KeyError (missing dictionary key), NameError (variable doesn't exist).

17. Reading & Writing Files

# Write (creates or overwrites the file)
with open("notes.txt", "w") as f:
    f.write("First line\n")
    f.write("Second line\n")

# Append (adds to the end)
with open("notes.txt", "a") as f:
    f.write("Third line\n")

# Read the whole file
with open("notes.txt", "r") as f:
    content = f.read()
print(content)

# Read line by line
with open("notes.txt") as f:
    for line in f:
        print(line.strip())

💡 with automatically closes the file for you when you're done.

18. Importing Modules

Python comes with lots of extra tools. Use import to load them.

import math
print(math.sqrt(16))     # 4.0
print(math.pi)           # 3.141592653589793
print(math.floor(3.7))   # 3
print(math.ceil(3.2))    # 4

import random
print(random.randint(1, 6))          # random whole number 1–6
print(random.choice(["a", "b", "c"]))  # random item
nums = [1, 2, 3, 4]
random.shuffle(nums)                 # mix up the list

from datetime import date
print(date.today())

import time
time.sleep(1)            # pause for 1 second

Mini project: number guessing game

import random

secret = random.randint(1, 20)
guesses = 0

while True:
    try:
        guess = int(input("Guess a number 1-20: "))
    except ValueError:
        print("Numbers only!")
        continue
    guesses += 1
    if guess < secret:
        print("Too low")
    elif guess > secret:
        print("Too high")
    else:
        print(f"Correct! You got it in {guesses} guesses.")
        break
